# 来世が決まるまで、ここにいて。

ユーザーの「徳ポイントで転生を管理する、無機質な天国」をもとにした、React / Vite製のテキストADV。第0話と、第1話の分岐シナリオ試作を収録。

## 起動

Windowsでは、このフォルダの `play.cmd` をダブルクリックするか、VSCodeのターミナルで以下を実行します。

```powershell
npm.cmd run dev -- --host localhost --port 5174 --strictPort
```

http://localhost:5174/ を開き、起動用ターミナルは閉じないでください。ポート使用中の場合は既存のサーバーを確認するか、別のポートを指定してください。初回に依存関係がない場合は `npm.cmd install` が必要です。

## 遊び方

- 「はじめる」でBGM・効果音を有効化します。
- 「次へ」またはSpace / Enterで文字送り。表示途中では全文を表示します。
- 行いに関する選択で徳が内部的に増減します。行き先の選択では増減しません。現在値は手帳から確認できます。カフェの4人・受付の会話へ分岐し、6種類の区切りを収録。
- 会話履歴と手帳をメニューから確認できます。
- セーブは1スロット。ブラウザのlocalStorageに保存します。同じブラウザ・同じポートで再開してください。ブラウザのデータ消去でセーブも消えます。
- 設定からBGM・効果音を個別調整、ミュート、音声再開できます。音量設定も保存されます。
- 本編ではまだ転生せず、第1話の「つづく」で終わります。旧版のセーブは対応する場面へ移行し、旧版の読了セーブはカフェの相手選択から再開します。

## 編集と検証

- `src/story.js`: 導入の改訂、分岐エンジン、発言者別の会話、保存の復元
- `src/chapters.js`: カフェ4人と受付の続編シナリオ
- `src/story-v1.js`: 旧版セーブ検証用データ・エンジン（導入の元データを兼ねる）
- `src/App.jsx`: 会話UI、文字送り、手帳、セーブ、設定
- `src/sound.js`: BGM切替、効果音の合成
- `src/App.css`: 画面とレスポンシブ対応
- `scripts/generate-audio.mjs`: オリジナルBGMの生成。`node scripts/generate-audio.mjs` でWAVを再生成
- `scripts/test-story.mjs`: 全3,249通りの経路、各地点での保存・復元、不正データ、選択の重複処理を検証
- `src/trial.js`: 初期裁判試作のデータ。現在のADVでは未使用

```powershell
node scripts/test-story.mjs
npm.cmd run lint
npm.cmd run build
```

画像・音源については `ASSETS.md` を参照。

## 第2話・議論編（2026-10-19）

タイトル画面または第1話の読了画面の「第2話」から開始。読了画面からは徳とカフェ訪問の有無を引き継ぐ。第2話の保存がある場合はそちらから再開する。3争点・5資料・3処理方針を収録。各争点で「詳しく聞く → 記録を示す → 別の解釈を示す」。誤答自体では減点しない。

第2話は独立した自動保存（`heaven-trial-v1`）。争点・選択肢の直前に戻れる分岐を最新40件保持。会話編の保存を上書きしない。現在の徳は右隅のDEBUG、結末では合計を表示する。

- `src/trial-data.js`：台本、証言、資料、結末
- `src/trial-engine.js`：議論判定、徳、アクション再生による保存検証
- `src/Trial.jsx` / `Trial.css`：議論画面、履歴、分岐、音声操作
- `src/voice.js`：ボイスの排他再生とBGM音量の自動抑制
- `node scripts/test-trial.mjs`：12経路・誤答・復元・音声競合のテスト

### Geminiボイス

ゆう=Achernar、まひる=Sulafat、ゆめ=Kore。9本の試聴後に採用。地の文・主人公・かみさまには今回ボイスを付けない。

第2話は23本中2本生成済み。残り21本はGeminiの429制限が継続したため、ユーザーの希望で無料枠の回復待ち。未生成分は「ボイス準備中」と表示し、存在しないファイルへの再生リクエストを出さない。自動再開・有料枠への切替はしない。

回復後に制作チャットで再開を依頼、または手動で以下を実行。`.env.local` に設定した `GEMINI_API_KEY` はNode側だけで読み、配信・コミットしない。

```powershell
node scripts/generate-trial-voices.mjs
npm.cmd run build
```

音声は `public/audio/trial/`。manifestの台本・声・演技指示ハッシュが一致する生成済みファイルを再利用する。22秒間隔、429時65秒待機・最大2回の再試行。キー、プロバイダーの生エラー、個人情報はログへ出さない。試聴ページは `node scripts/preview-voice-audition.mjs` で `http://127.0.0.1:5176/` に配信。
